# 尺寸预设

用户没说平台时默认小红书 3:4。用户报了平台按下表取值；报了自定义宽×高直接用。
所选尺寸即"画布宽×画布高"，贯穿骨架、可调版缩放基准、导出 viewport 和尺寸校验。

| 预设 | 尺寸（宽×高） | 说明 |
|---|---|---|
| 小红书封面（默认） | 1086×1448 | 3:4 竖版 |
| 公众号头图 | 900×383 | 2.35:1 横版 |
| B站封面 | 1146×717 | 16:10 横版 |
| 方图 | 1080×1080 | 1:1，通用 |
| 视频封面 | 1920×1080 | 16:9 横版 |
| 竖版视频封面 | 1080×1920 | 9:16，抖音/视频号 |

## 使用规则

- 分析参考图时先判断它本身的比例；参考图与目标尺寸比例差异大时（如横版参考图做竖版封面），
  在第 0 步向用户确认一句，并说明版式会按目标比例重新布局，只保留设计语言。
- 横版画布的"缩略图可读性"自查按 320px 宽缩略图判断；竖版按 200px 宽。
- 导出自查的尺寸校验必须等于所选画布尺寸，不是固定 1086×1448。
